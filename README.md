# HR-Employee-Attrition-Dashboard
Project Overview :
This project is an interactive HR Employee Attrition Dashboard created using Microsoft Power BI. The dashboard analyzes employee data to understand attrition patterns and identify factors that may contribute to employees leaving an organization.

Objective :
The main objectives of this project are to:
Analyze employee attrition patterns,
Identify factors associated with employee turnover,
Create an interactive dashboard for exploring HR data,
Analyze attrition based on department, age group, gender, job role, overtime, business travel, education, and marital status,
Present important findings using KPI cards and interactive visualizations.

Tools Used:
Microsoft Power BI
DAX for creating measures and KPIs
Key KPIs:
Total Employees: 1,470,
Attrition Count: 237,
Attrition Rate: 16.12%,
Average Age: 36.92,
Average Monthly Income: 6.50K,

Interactive Filters:
The dashboard includes interactive filters for:
Department,
Age Group,
Gender,
Job Role,
These filters allow users to explore the dashboard based on different employee groups.

Dashboard Analysis:
The dashboard provides visual analysis of:
Attrition by Department,
Attrition by Job Role,
Attrition by Age Group,
Attrition by Gender,
Attrition by Overtime,
Attrition by Education,
Attrition by Business Travel,
Attrition by Marital Status,

Key Insights:
The dashboard helps identify patterns in employee attrition by comparing different employee characteristics and workplace factors. It provides insights into how factors such as department, job role, age group, overtime, business travel, education, and marital status are associated with employee attrition.

Project Outcome:
This project demonstrates the use of Power BI for HR data analysis and interactive data visualization. The dashboard provides an easy-to-understand visual representation of employee attrition and helps users explore the factors associated with employee turnover.
